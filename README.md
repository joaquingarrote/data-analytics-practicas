Ventas Tech DB
Base de datos relacional desarrollada en SQL Server para gestionar una tienda de productos tecnológicos.

Objetivo: Objetivo: Diseñar e implementar una base de datos relacional para gestionar clientes, productos, categorías y ventas, aplicando consultas SQL para relacionar información, identificar registros sin actividad y analizar la facturación por períodos.

Tablas principales:
- Categorias: categorías de productos.
- Clientes: información de clientes.
- Productos: catálogo, precios y stock.
- Ventas: registro de ventas realizadas.
Relaciones:
- Categorias → Productos (1).
- Clientes → Ventas (1).
- Productos → Ventas (1).
Consultas SQL: INNER JOIN, LEFT JOIN, UNION ALL, GROUP BY y funciones de agregación.

Clientes → Ventas (1).

Productos → Ventas (1).

Tecnologías: SQL Server y T-SQL.
