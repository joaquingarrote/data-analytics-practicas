Ventas Tech DB

Base de datos relacional desarrollada en SQL Server para gestionar una tienda de productos tecnológicos.

Objetivo: Aplicar conceptos de SQL para diseñar y administrar una base de datos relacional.

Alcance: Creación de tablas, relaciones, restricciones de integridad, inserción y consulta de datos.

Tablas principales:

Categorias: categorías de productos.

Clientes: información de los clientes.

Productos: catálogo, precios y stock.

Ventas: registro de ventas realizadas.

Relaciones entre tablas:

Categorias → Productos (1).

Clientes → Ventas (1).

Productos → Ventas (1).

Tecnologías: SQL Server y T-SQL.
